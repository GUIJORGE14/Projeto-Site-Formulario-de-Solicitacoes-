# Projeto Site - Formulário de Solicitações

Projeto desenvolvido para a empresa Novvax.

## Minha contribuição
- Desenvolvimento do formulário
- Integração com backend
- Ajustes de layout

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- C#
- Json

## Projeto
Este projeto tem como intuito criar uma ferramenta interna para empresa Novvax, com a funcionalidade de facilitar os serviços solicitados pela a empresa. 
O foco é para que um dia esta ferramenta seja usada além da empresa, ajudando a Novvax a automatizar e organizar tarefas.
